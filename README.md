A lightning-fast, highly accessible local server for mocking API responses. Designed specifically for frontend developers who need to test UIs immediately without waiting for backend readiness.

## ✨ Features
* **Zero Configuration:** Just run it and you have a RESTful API.
* **Hot Reloading:** Change your `db.json` and get instant updates.
* **CORS Enabled:** Ready to be consumed by any frontend framework (React, Vue, Angular).
* **Lightweight:** Minimal dependencies, blazing fast startup.
