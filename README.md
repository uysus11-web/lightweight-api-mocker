# 🚀 Lightweight API Mocker

![license](https://img.shields.io/badge/license-MIT-green) ![version](https://img.shields.io/badge/version-2.0.0-blue) ![node](https://img.shields.io/badge/node->=14.0.0-brightgreen)

A lightning-fast, highly accessible local server for mocking API responses instantly. Designed specifically for frontend developers who need to test UIs immediately without waiting for backend readiness.

## ✨ Features (v2.0.0 Update)

* **Zero Configuration:** Just run it and you have a RESTful API.
* **Full CRUD Support:** Fully supports `GET`, `POST`, `PUT`, and `DELETE` operations.
* **🔥 Dynamic Data Generation:** Instantly generate hundreds of realistic fake user profiles (names, emails, avatars) with a single command using `faker.js`!
* **Hot Reloading:** Change your `db.json` and get instant updates.
* **CORS Enabled:** Ready to be consumed by React, Vue, Angular, etc.
