# Contributing to Lightweight API Mocker

First off, thank you for considering contributing to this project! It's people like you that make open-source such a great community.

## How can I contribute?

1. **Report bugs:** Open an issue and describe the bug clearly.
2. **Suggest features:** Have a cool idea to make this mocker better? Let us know!
3. **Submit a Pull Request:**
   - Fork the repository.
   - Create a new branch (`git checkout -b feature/my-cool-feature`).
   - Make your changes and test them.
   - Commit your changes (`git commit -m 'Add some feature'`).
   - Push to the branch (`git push origin feature/my-cool-feature`).
   - Open a Pull Request.

Please make sure your code follows the existing style and keep dependencies as lightweight as possible.
